アイコン凡例

表示灯（色＋形＋文字で判別）

緑の丸 ・ 稼働中
直近 60 秒以内にツール実行イベントあり
黄の三角 ・ 入力待ち
許可要求・質問、または作業完了後の指示待ち
朱の四角 ・ 異常
心拍途絶（オフライン）または API エラー

モデル表示

Opus 5.5O
Sonnet 5.5S
Haiku 4.5H
Fable 5.1F
セッションは枠付きラベル、プレイヤーは頭文字の丸で表示します。色に加えて名称・頭文字を必ず併記します。

役割（オーケストレーション）

指揮 ×4 コンダクター（タクト）と指揮中のプレイヤー数
SSonnet Claude のプレイヤー（右端の点が状態）
Codex Codex CLI のプレイヤー（六角形＋プロンプト記号）

接続元

PC（Claude Code）
hooks・statusLine で受信、Channel で指示を送信
Cowork（クラウド）
OTel で受信、状態は推定 ・ 閲覧のみ・推定

ゲージ

コンテキスト 38%
コンテキスト 71% 圧縮間近
70% 以上で黄色に変わり「圧縮間近」と表示します。

アラートと表示灯デバイス

危険操作を停止実行前フックで止め、許可か却下を選ぶ
ファイル競合同じファイルを複数が編集
放置アラート入力待ちがしきい値を超過
物理表示灯最も重い状態を机上の LED に同期
