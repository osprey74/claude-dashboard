PC 側エージェントの使い方

Claude Code を使う PC にエージェントを入れると、その PC のセッションが管制室に表示されます。

準備：この PC 用のトークン

Mac Mini でトークンを発行します（平文はこのときだけ表示されます）。

bun apps/server/src/cli.ts add-host office-win

macOS（arm64）

  1. kanseishitsu-agent-macos-arm64 をダウンロードします。
  2. ターミナルでダウンロード先へ移動し、実行権限を付けます。 
    cd ~/Downloads
chmod +x kanseishitsu-agent-macos-arm64
  3. ブラウザーでダウンロードしたファイルには隔離の印（com.apple.quarantine）が付き、そのままでは「開発元を検証できない」などと表示されて起動できません。印を外します。 
    xattr -d com.apple.quarantine kanseishitsu-agent-macos-arm64

    「No such xattr」と表示された場合は、印が付いていないためそのまま進めます。

  4. 設定を行います。サーバーの URL・トークン・この PC の表示名を聞かれます。 
    ./kanseishitsu-agent-macos-arm64 setup            # 設定ファイルの作成と、登録内容の表示のみ
./kanseishitsu-agent-macos-arm64 setup --apply    # 内容を確認して ~/.claude/settings.json に追記

setup は実行ファイルを ~/.kanseishitsu/bin/ にコピーして使います。ダウンロードしたファイルは、setup のあと削除してかまいません。

Windows（x64）

  1. kanseishitsu-agent-windows-x64.exe をダウンロードします。
  2. PowerShell でダウンロード先へ移動し、設定を行います。 
    cd ~\Downloads
.\kanseishitsu-agent-windows-x64.exe setup
.\kanseishitsu-agent-windows-x64.exe setup --apply

「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選びます。PowerShell で Unblock-File .\kanseishitsu-agent-windows-x64.exe を実行してから起動する方法もあります。

登録のあと

  • 新しく起動した Claude Code のセッションから送信が始まります（起動済みのセッションは対象外です）。
  • statusLine が既に設定されている場合は上書きせず、警告だけを出します。
  • /plugin の Installed タブに kanseishitsu-usage が出ていれば、VS Code・Desktop 向けの利用枠の mod も読み込まれています。
  • VS Code で使っていて、セッションは表示されるのに利用枠が届かないときは、Claude Code の拡張機能を最新版に更新してください。古い拡張機能では利用枠の mod が動かないことがあります。

更新するとき

新しい実行ファイルをダウンロードし、同じ手順（macOS は実行権限と隔離の印の解除も）で setup --apply を実行します。前回の入力が既定値として表示されるため、Enter で進められます。
